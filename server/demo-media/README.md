# Yerel demo videolar

Yalnızca geliştirme kataloğunda kullanılan, kısa ve 480 piksele küçültülmüş temsilî klipler. Gerçek ürün tanıtımı değildir. Herkese açık örneklerin erişilebilir olması üretimde yeniden kullanım hakkı anlamına gelmez; canlı katalog için satıcının kendi medyası kullanılmalıdır.

- `style.mp4`: Cloudinary shoppable video örneği, https://cloudinary.com/blog/shoppable-videos-next-js-e-commerce-store — kaynak `hackit-africa/video/upload/v1745525294/shoppable-video/shoppable_demo`.
- `coffee.mp4`: Cloudinary watermark örneği, https://cloudinary.com/blog/guest_post/add-branding-watermark-to-video-with-react-and-cloudinary — kaynak `jlengstorf/video/upload/mediajams/disappointed-coffee`.
- `hourglass.mp4`: Cloudinary video katmanları demo kaynağı, https://cloudinary.com/documentation/video_layers — kaynak `demo/video/upload/hourglass_timer`.

Dosyalar yalnızca seed açıkken `/demo-media` altında sunulur. Posterler ve ürün fotoğrafları uzaktaki kaynaklardan yüklenir.
